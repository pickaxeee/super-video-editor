# Super Video Editor

A desktop video editor in the spirit of Adobe Premiere Pro: a multi-track
timeline, clip trimming, transitions and effects, titles, audio mixing, and
export presets for YouTube and social.

## Status

Early planning. Nothing is implemented yet. This repo will hold the design
notes, the app source, and build scripts as the project takes shape.

## Planned features

- Project bin with media import (video, audio, images)
- Multi-track timeline with ripple, roll, slip, and slide edits
- Keyframable effects and transitions
- Title and caption tools
- Audio mixer with per-track levels and basic EQ
- Render queue with H.264 / H.265 export presets

## Planned stack

To be decided. Candidates under consideration are an Electron + React UI
with an FFmpeg-backed render pipeline, or a native app using Qt.
